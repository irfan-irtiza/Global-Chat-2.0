🌍 IRFAN Global Chat

A modern real-time global chat web application that allows users to communicate instantly in a clean, fast, and responsive interface.

🔗 Live App:
https://rfan-globalchat.web.app

📌 Overview

IRFAN Global Chat is a lightweight web-based messaging platform designed for fast communication with a smooth user experience. The application focuses on modern UI design, real-time interaction, and mobile compatibility.

This project demonstrates modern frontend development practices including responsive layouts, optimized UI components, and interactive chat functionality.
